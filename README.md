# 💰 BütçePilot

**BütçePilot 7.4** — kişisel bütçe ve harcama takibi için geliştirilmiş modern bir web uygulamasıdır.

## ✨ Özellikler

- 💰 Gelir ve gider takibi
- 📊 Bütçe durumu
- 📅 Aylık finansal kayıtlar
- 📈 Aylık veri analizi
- 📱 Mobil uyumlu arayüz
- 📲 PWA desteği
- ⚡ Service Worker

## 🆕 Sürüm 7.4

7.4 sürümünde aylık veri yönetimi ve özellikle `2026-10` gibi ay formatındaki kayıtların okunması ve analiz edilmesi üzerine geliştirmeler yapılmıştır.

## 🛠️ Teknolojiler

- HTML
- CSS
- JavaScript
- Progressive Web App (PWA)
- Web App Manifest
- Service Worker
